# The Vantage — Logo & Social Image Prompts

Drop these directly into Midjourney, DALL-E 3, Imagen, Flux, or any image model.
Every prompt encodes the brand kit explicitly: bone paper, ink type, champagne /
brass accents, Playfair Display Italic wordmark, Space Mono caps for eyebrow
labels. Specify the dimensions in the model UI separately (Midjourney `--ar`,
DALL-E size parameter, Imagen aspect_ratio, etc).

---

## 0. Brand reference (paste at top of every prompt for consistency)

```
Brand: The Vantage. Luxury real-estate magazine aesthetic. Bone-paper
background (#F4EFE6), ink type (#0E0E0C), champagne gold accent (#C9A96E),
brass label color (#8C7A52), rust editorial accent (#8C3F2E). Wordmark "The
Vantage" set in Playfair Display Italic, large display weight, tight letter
spacing, deep contrast. Secondary text "EST. 2026" in Space Mono uppercase,
brass color, wide 0.32em tracking. Editorial, cinematic, never corporate.
No emoji. No rounded corners. Flat hairline rules at 12% opacity ink. Long
soft ink shadows only. Single ornament style: a 28px champagne hairline
preceding eyebrow labels.
```

## 7. Composition rules that apply to every prompt

If the model produces something that feels off, add these as suffixes:

- `Never pure white or pure black — bone and ink only.`
- `No rounded corners. Every rectangle and rule is sharp.`
- `No emoji or pictogram clichés. The brand uses only one ornament: the champagne hairline rule preceding eyebrow labels.`
- `No drop shadows. If any shadow is needed, it's a long soft ink shadow with 34% opacity.`
- `Sharp, magazine-grade typography. Playfair Display Italic for display, Space Mono caps for eyebrow labels, Inter or Cormorant Garamond for body if any.`
- `Editorial. Restrained. Never tech-startup or SaaS.`

---

## 8. Model-specific suffixes

### Midjourney v6+

Add at end: `--ar [width]:[height] --style raw --stylize 200`

### DALL-E 3

Add at start: `Create a [orientation] image with these exact specifications:` and the model will more faithfully reproduce hex colors and typography names.

### Imagen 3 / 4

Add at end: `Photorealistic editorial photography style, magazine print quality, 35mm grain, sharp typography.`

### Flux

Add at end: `Editorial magazine layout, sharp text rendering, brand identity design.` Flux is the strongest at typography fidelity right now — use it for anything with a wordmark.

---

End of prompts. Reorder, mix, and adjust the headlines and colors — but
keep the typographic system (Playfair Italic + Space Mono caps + champagne
hairline) consistent across every output. That's what gives the social
presence its single voice.
